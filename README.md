# Abdullah Ansari — Developer Portfolio

A cinematic, responsive personal portfolio for Abdullah Ansari, a second-year B.Tech Computer Science Engineering student specializing in Cyber Security.

**GitHub:** https://github.com/GlitchedPhoenix38

## Features
- Dark editorial visual design with custom CSS motion and orbital 3D-inspired artwork.
- Responsive navigation and layouts.
- Selected projects linked to their source repositories.
- About, technical interests, and collaboration sections.
- Scroll progress and reduced-motion support.
- No build step or package installation required.

## Deploy with GitHub Pages
1. Open repository **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch `main` and folder `/ (root)`.
4. Save and wait for GitHub Pages to publish.

The expected URL is `https://glitchedphoenix38.github.io/portfolioabdullah/` after Pages is enabled.
